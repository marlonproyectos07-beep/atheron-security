No es un documento de ideas.

------------------------------------------------------------
1. ORIGEN Y TESIS FUNDADORA
------------------------------------------------------------

La chispa fundadora surgió al observar aproximadamente 1.000
turistas chinos salir de la Mina de Sal de Zipaquirá sin una
oferta local suficientemente articulada de restaurante, hotel y
experiencias.

Atheron ya venía acumulando experiencia real en hospitalidad
mediante la remodelación y operación de siete casas para
hospedaje.

La experiencia reforzó una idea:

No basta con tener activos o servicios aislados.
Hay que conectarlos en un sistema.

Atheron nace de observar una falla:

La oferta está fragmentada.

Una misma persona puede:

- visitar la Catedral de Sal;
- dormir;
- comer;
- usar transporte;
- comprar una experiencia;
- requerir seguridad para su hogar;
- requerir seguridad para su empresa;

y cada relación comercial vive aislada.

La tesis de Atheron es integrar esas relaciones mediante:

- tecnología;
- datos;
- automatización;
- servicio;
- alianzas reales.

Zipaquirá será el laboratorio.

El objetivo NO es quedarse en Zipaquirá.

El objetivo es construir aquí un sistema que después pueda
desplegarse en otras ciudades de Colombia y, con el tiempo, en
otros mercados.

Atheron no debe comportarse como varios negocios desconectados.

Debe funcionar como un ecosistema.

Cada:

- cliente;
- compra;
- estadía;
- referido;
- aliado;
- experiencia;

alimenta una relación de largo plazo.

------------------------------------------------------------
2. MISIÓN
------------------------------------------------------------

Construir un ecosistema empresarial tecnológico que conecte:

- seguridad;
- hospitalidad;
- comercio local;
- experiencias;
- servicios;

mediante una relación única con el cliente, apoyada por:

- Odoo;
- inteligencia artificial;
- automatización;
- red de aliados verificables.

Atheron debe ayudar a sus clientes a:

- comprar mejor;
- vivir mejor las ciudades;
- proteger hogares;
- proteger negocios;
- acceder progresivamente a nuevos beneficios.

Al mismo tiempo debe crear:

- empresas rentables;
- empleo;
- talento;
- oportunidades de crecimiento;
- oportunidades para colaboradores;
- oportunidades para aliados;
- oportunidades futuras para inversionistas.

Atheron también debe formar personas.

El crecimiento debe crear rutas para que colaboradores:

- desarrollen capacidades;
- asuman responsabilidad;
- asuman liderazgo;
- puedan llegar a dirección;
- puedan liderar unidades;
- y, donde exista mérito, estructura y viabilidad, puedan
  evolucionar hacia participación estratégica.

Misión operativa Atheron Security:

Convertir cada solución de seguridad en una experiencia comercial:

- clara;
- visual;
- verificable;
- fácil de comprar;
- fácil de cotizar;
- fácil de instalar;
- fácil de financiar;
- fácil de ampliar;
- fácil de recomendar.

------------------------------------------------------------
3. VISIÓN
------------------------------------------------------------

Convertir Atheron en una red empresarial replicable por ciudades,
nacida en Zipaquirá, en la que una sola relación con el cliente
pueda atravesar múltiples líneas de negocio sin perder trazabilidad.

La visión de largo plazo es que una persona pueda:

- alojarse en Atheron o en un aliado;
- comprar una cámara o un sistema de seguridad;
- recibir beneficios en restaurantes;
- recibir beneficios en experiencias;
- recomendar nuevos clientes;
- ampliar sus sistemas;
- acceder a nuevas soluciones;
- ser reconocida en otra ciudad;
- y, cuando exista encaje real, convertirse en aliado estratégico.

El cliente no debe sentir que habla con negocios aislados.

Debe sentirse reconocido por ATHERON.

6. MOTOR DIFERENCIADOR: ATHERON LOOP
------------------------------------------------------------

Nombre de trabajo:
ATHERON LOOP

Todavía no es nombre comercial definitivo.

Idea:

CADA TRANSACCIÓN DEBE ABRIR LA SIGUIENTE RELACIÓN ÚTIL.

Ejemplo:

Cliente compra cámara
→ queda identificado
→ Odoo registra
→ entra al ecosistema
→ recibe beneficio
→ se mide su uso
→ se genera siguiente oportunidad.

No queremos un programa genérico de puntos.

Queremos:

MOTOR DE PRIVILEGIOS + NEXT BEST ACTION.

6.1 ESCALERA DE RELACIÓN

Nivel 0 — Visitante

Nivel 1 — Cliente

Nivel 2 — Cliente recurrente

Nivel 3 — Embajador

Nivel 4 — Cliente estratégico

Nivel 5 — Aliado / oportunidad estratégica

6.2 PROGRESIÓN COMERCIAL

Hipótesis:

5% → 10% → 15% → 20%

en compras posteriores dentro de líneas elegibles.

NO es aún política pública.

Debe validarse contra:

- margen;
- CAC;
- recurrencia;
- costo del beneficio;
- LTV;
- caja.

Nunca deben acumularse descuentos que destruyan rentabilidad.

6.3 VENTA CRUZADA

Ejemplos:

Security
→ hospedaje.

Hospedaje
→ Security.

Hotel aliado
→ restaurante aliado.

Restaurante
→ futura estadía.

Referido
→ beneficio.

No todo beneficio es descuento.

También puede ser:

- upgrade;
- bono;
- check-in preferente;
- asesoría;
- instalación subsidiada;
- beneficio familiar;
- experiencia;
- acceso;
- servicio de bajo costo marginal.

6.4 SOSTENIBILIDAD

Cada beneficio debe tener:

- costo máximo;
- sponsor económico;
- margen protegido;
- vencimiento;
- condición;
- responsable;
- redención registrada.

9. MODELO COMERCIAL SECURITY
------------------------------------------------------------

Líneas:

HOGAR
COMERCIAL
INDUSTRIAL

Hogar:
compra rápida / despacho / instalación.

Comercial:
venta por necesidad.

Industrial:
proyecto / ingeniería / diagnóstico.

Regla financiera actual para catálogo trabajado:

Costo directo =
equipo con impuestos
+ memoria si aplica
+ mano de obra
+ materiales
+ costos directos verificados.

Precio crédito =
costo directo ÷ 0,52

Precio contado =
precio crédito × 0,85

Objetivo aproximado actual:
margen bruto contado cercano a 38,8% antes de costos extraordinarios.

La inicial del crédito no debe dejar a Atheron financiando el
capital invertido.

Retoma:
solo equipos previamente vendidos e instalados por Atheron,
tras inspección.

Referidos:
base conceptual actual 5% por cierre.
Pendiente formalización.
